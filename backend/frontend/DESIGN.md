## 1. 设计令牌（四语义槽，写进 CSS `:root`）

| 槽 | 令牌 | 值 | 用途 |
|---|---|---|---|
| 底 | `--paper` / `--paper-2` / `--card` | `#FAF6ED` / `#F5EFE1` / `#FFFDF8` | 全站底色 / 悬停与次级面 / 唯一一种白卡 |
| 字 | `--ink` / `--ink-2` / `--muted` | `#1B1E22` / `#3E3A31` / `#8C8371` | 标题 / 正文 / 次文与微标签 |
| 线·主色 | `--hair` / `--green` / `--green-deep` / `--green-tint` | `#E5DECC` / `#1E7C50` / `#14613C` / `#E9F1E4` | 结构细线 / **唯一 accent** / 深色变体 / 选中与浅底 |
| 警示 | `--orange` | `#DD8A3E` | **仅**未解锁·警示标记，不做按钮色 |
| 禁用 | `--disabled-ink` / `--disabled-bg` | `#6B6252` / `#F1EBDD` | 置灰控件文字（暖纸上 ≥4.5:1）/ 置灰底 |

- **accent 唯一性**：全站只此一个 accent = 草绿 `#1E7C50`（深色 `#14613C`）。旧暗棕 `#9A6B3F` 已废弃，**不得回归**（回归即回滚）。
- **圆角统一一套**：卡 `--r-card:16px` / 按钮 `--r-btn:14px` / 微块 `--r-chip:8px`。不许混用其它圆角。
- **字体栈**：display `'Archivo Black','Archivo','Noto Sans SC','PingFang SC',sans-serif`；正文 `'Archivo','Noto Sans SC','PingFang SC','Hiragino Sans GB',sans-serif`。**不引外链字体、不引任何依赖/框架**（UI-004）；未装 Archivo 时按栈回退。

## 2. 字号尺度（移动优先，四档拉开）

| 层级 | 字号 / 字重 | 用途 |
|---|---|---|
| 大标题 | `34–40px / 900`（`--disp`） | 页头主句（`clamp(34px,9.5vw,40px)`），断行处手动控制 |
| 区块题 | `22px / 800` | 复习题、区块标题（`.q` / `.h2`） |
| 正文 | **`17.5px / 400`，行高 1.75，行宽 ≤70ch** | 卡面、要点、正文。**不得低于 17px** |
| 次文 | `15px / 400` | 说明、时间估算（`.sub` / `.muted`） |
| 微标签 | `11.5px / 800 · 字距 .16em · 大写` | 出处「书 · 章 · 概念」、状态（`.mlabel` / `.sectitle`） |
| 数字 | `font-variant-numeric: tabular-nums` | 计数 / 连胜 / 进度 / 题号，全部等宽对齐（body 全局 + `.tnum`） |

## 3. 结构语法

- **结构靠 1px `--hair` 细线 + 留白**，不靠盒子。白卡 `.state` **只有一种样式**（error / empty 用）。
- **相邻可交互块的间隙（UI-013）**：任何相邻可交互块，**竖向 ≥12px、横向 ≥10px**；hairline 细线**不得作为唯一分隔**。
  行式入口（`.row` / `.chap` / `.progline`）一律做成**独立块** —— 暖纸卡底 `--card` + 1px `--hair` 边 + `14px` 圆角，
  列表容器 `.rowlist` 用 `gap:12px` 撑开；保留 editorial 语法（大字号、细线、**无嵌套卡**）。
  未解锁章行同样块化并置灰（`.row.disabled`，UI-003）。
- **禁止卡片套卡片**：任何白卡内不得再出现白卡。展开章内的概念行是**平级块**（`.chap` 本体透明，只有 `summary` 是卡），不是「大卡里嵌小卡」。
- **一屏只有一个主行动**：深绿实心大按钮 `.primary`（首页 = 「开始复习 N 张」+ 一行时间估算）；其余入口是独立块行 `.row`（左标题+次文，右箭头）。
- **页面顺序**（照对照稿）：
  - **首页**（v0.5.5 重构）：顶栏（logo + 「N 天连续」）→ 大标题 = **每日格言**（HOME-001，当天固定、按日轮转，无作者署名）→
    一行汇总（`2 本书 · 20 章 · 237 张卡 · 到期 0 · 新卡 30`）+
    一行「本周概况」摘要（`本周：复习 N 张 · 作答 M 题 · 正确率 X`，读 `/api/report` 同一字段；0 作答 → `—`）→
    主按钮「开始复习 N 张」→
    **今日任务**块（`今日复习 N 张` / `出题 M 题` 两子项，各自可勾：`.row.task` 右侧 `.tick` 纯 CSS 勾选框，`complete` 时 `.tick.on` 草绿）→
    **快捷入口两列网格**（`.rowlist.grid`，竖向/横向 gap 均 `12px`、**不横滑**，UI-001/UI-013）：
    出题自测 / 知识卡片 / 错题本 / **复习计划** / **薄弱点** / **本周概况** 六格（行式入口仍独立块化）→
    「学科进度」块行（学科名 + 细进度条 + 百分比 + **`已掌握 x / 已学 y`**），点进钻取。
    连胜只读（页头常显、不催促）。分母 0 → 「未开始」（不除零）。
    **口径（MAST-004）**：掌握度处**同时**给分子分母；总卡数只能**另写**「共 N 张」，**不得与掌握度同括号**。
    **v0.10.1 数值去重**：渲染环星的层级（首页学科块 / 书页 `.meter` / 学科页书行），文字行只留「已学 x / 共 y · 状态」，
    掌握度/覆盖率数字只出现一次（环心写覆盖率、星旁写掌握度）；未渲染环星的层级（学科列表 / 章行）文字行保留双数。
  - **学科页 / 书页**：面包屑 `学科 › 书` + `已解锁 x / y 章` 微标签 + **书级掌握度计量**（`.meter`：进度条 + 百分比 +
    **`已掌握 x / 已学 y`**）+ **常显口径说明句**（原文固定，MAST-004）：
    「掌握度 = 已掌握卡数 ÷ 已学卡数；未学卡不计入分母（卡级按 0/1 计）」+
    章行独立块列表（已解锁行 `.chap` 带**章级进度条 + 百分比 + 分子分母**、可展开；**未解锁行常显 + 置灰 + 写明原因**）；
    学科页的书行同样带**书级进度条 + 百分比 + 分子分母**。四级掌握度见 §3 末条。
  - **概念行（章展开 / `#/chapter/<id>`，MAST-005）**：每行 = 概念名 + **后端下发的状态**
    （`.mlabel.cm`：同态 → 四态标签；多态 → `未学习 2 · 学习中 1`，顺序固定 新→学→复→掌）+ `N 张卡`。
    状态与计数**一律后端下发**（`/api/concepts` 的 `status_label` / `status_counts`），前端**只读、零映射、零拼接**。
  - **复习卡（闪卡）**：微标签出处（`书 · 章 · 概念`）→ 大问题 22px/800（正面）→ 点击卡面 3D 翻转 → 背面要点 hairline 列表（**禁嵌套卡 / 禁彩色左边框**）→ 卡片下方提示行 → 「记得」深绿实心 / 「忘了」描边（按钮保留，手势只是更快的一条路）。手势条款见 §10。
  - **测验页（客观题，v0.5.4；v0.5.5 视觉打磨）**：进度「第 x / N 题」→ 微标签 `书 · 章` → 题干 22/800 → **选项独立块列表**（`.opts` 竖向 `gap:12px`；
    选择题为选项按钮、是非题为「对 · 错」两键）→ 点选（`.opt.sel` 草绿描边）→「提交」主按钮（`.qfoot`，未选时**常显置灰 + `.why` 写明原因**）
    → 立刻判分：**正确项标草绿**（`.opt.correct` + 微标签「正确答案」）、**我的错选标陶橙警示**（`.opt.wrong` + 微标签「你的选择」）
    → 「下一题」→ 结束页「答对 x/y · 得分 z」+ 错题明细。题目文本可换行（`white-space:normal`），**不横滑**。
    判分只在后端（前端不判分），会话响应**不含** `answer_key`。**测验页不再有翻卡/滑动手势**（UI-014 修订）。
  - **错题本页（`#/wrong`，WRONG-001）**：面包屑 + 「错题本」微标签 + 条数 → 说明行 →
    逐卡 `.chap` 独立块（`summary` = 卡面 + `错 N 次`；展开体 = 题目 + `.points` 对照「正确答案」（草绿 `.right`）/
    「我的答案」（陶橙 `.mine`）+ 「重刷这一题」按钮）；空态 = `.state` 有话说（「还没有错题」+ 指路「去出题自测」），绝不空白。
  - **复习计划页（`#/plan`，PLAN-001）**：面包屑 `首页 › 复习计划` + 「复习计划」微标签 + 条数 → 说明行 →
    **行式独立块列表**：每行 = 卡面（`.l > b`）+ 出处 `书 · 章 · 概念` + 右端**间隔**（`.r.when`，已到期草绿 `.due`）。
    间隔文案**一律来自后端** `when_label`（前端不另算：`已到期` / `N 天后` / `N 小时后` / `N 分钟后`）；
    **已到期行可点 → `#/review` 直接作答**（复用复习卡路径），未到期行为**信息块**（`.row.plain`，不可点、不置灰）。
    空态 = `.state` 有话说（「还没有排上复习的卡」+ 指路「去复习」），绝不空白。
  - **薄弱点页（`#/weak`，WEAK-001）**：面包屑 + 「薄弱点」微标签 + 章数 → 说明行 →
    逐**章** `.chap` 独立块（`summary` = 章名 + `书 · 错 N 次 · 涉及 K 张卡`；展开体 = 该章涉及的卡行 `.row.plain` + 各自错次）；
    **按章聚合、按错次降序**；空态 = `.state` 有话说（「还没有薄弱章」+ 指路「去出题自测」），绝不空白。
  - **本周概况页（`#/report`，RPT-001）**：面包屑 + 大标题「本周概况」+「统计自本周一 00:00 起」说明 →
    四行信息块（`.row.plain`：复习卡数 / 出题作答 / 判对数 / 正确率）+ 「最弱一章」块（有则点进 `#/weak`，无则有话说）。
    正确率**只读后端 `accuracy`**（0 作答 → `—`，**不显 `0%`**）；前端**不自算**。空态（全 0）也有话说，绝不空白。
- **四级掌握度（MAST-002 / MAST-004）**：学科 / 书 / 章 / 卡**每级都有进度条 + 百分比**且可钻取（学科 → 书 → 章 → 卡）——
  学科级 = 首页/学科列表 `.progline .bar`；书级 = 书页 `.meter .bar`；章级 = 章行 `.chap .bar`；
  卡级 = 卡片页 `.cm` 四态标记（`未学习 / 学习中 / 复习中 / 已掌握`，**后端下发、令牌色文字、非 emoji**）。
  分子分母严格按 MAST-001，且**每一级出现处都必须同时显示** `已掌握 {num} / 已学 {den}`
  （数值只读后端 `mastery.num` / `mastery.den`，**前端零计算**）。
  **禁用总卡数当分母**（旧 `已学 2/237` 混写属缺陷）；学科页与书页**常显口径说明句**（原文见 §3，不得改写）。
- **四级掌握度数值去重（MAST-004 v0.10.1 修订）**：某层级已渲染「覆盖率环形图 + 掌握度五星」时，
  其**文字行只留 `已学 x / 共 y · 状态`**（掌握度/覆盖率数字不再重复）；**未渲染环星的层级**（学科列表 `.row.prog`、
  章行 `.chap summary`）文字行**保留双数** `掌握度 m% · 覆盖率 c%`。环心写覆盖率、星旁写掌握度，
  **全站每个数字在每个层级只出现一次**。触发点：任何渲染层级汇总的改动；覆盖路径：学科页 / 书页 / 章页 / 进度页。
- **概念行状态（MAST-005）**：章展开与 `#/chapter/<id>` 的**每个概念行**都显示卡状态（同态 → 四态标签；
  多态 → `未学习 2 · 学习中 1`）；一律读 `/api/concepts` 的 `status_label` / `status_counts`，前端零映射零拼接。

## 4. 状态齐全（缺一不可）

| 状态 | 要求 |
|---|---|
| hover | 行 `background: --paper-2`；主行动·按钮抬升 6px |
| `:active` | `transform: translateY(1px)` |
| `:disabled` | **常显 + 置灰 + 写明原因**（`.why`），绝不按条件隐藏（UI-003） |
| loading | 静态骨架 + 「加载中…」，**不做圆形转圈** |
| error | `errorBox`/`.state` 保留，套新语法：微标签 + 标题 + 原因 + 一句怎么办 + 返回入口 |
| empty | 有构图（微标签 + 标题 + hairline + 说明）且**写明「怎么产生内容」** |

## 5. 浏览器原生面（也要设计）

- `::selection` → `--green-tint` 底 / `--green-deep` 字。
- `caret-color: var(--green)`。
- 滚动条：窄条（10px）、暖纸轨道、`--hair` 滑块。
- `:focus-visible` → 草绿 2px 焦点环（`outline-offset:2px`）。**不许 `outline:none` 了事**。
- 链接：`--green-deep` + `text-underline-offset:3px`。

## 6. 动效预算

- **一次**「作者化」进场：列表错峰 `fadeUp`（`.rise` + `--d` 控延迟，`cubic-bezier(.16,1.22,.35,1)`）。
- **进场动画不得位移「可交互块」与列表容器**（UI-013 硬化，v0.5.3）：凡 `.rise` 落在 `a` / `button` /
  `.row` / `.btn` / `.primary` / `.progline` / `.chap` / `.rowlist` 上时，只做**透明度淡入 `fadeIn`**，不做 `translateY`。
  原因：入场瞬间的位移会让相邻可交互块的**实测**竖向间隙从 `12px` 掉到 ~`2px`（`make ui-audit` ① 由此变红）。
  位移型 `fadeUp` 只留给页面级标题与状态块（`.display` / `.sub` / `.state`）。
- hover 抬升 `6px`；`:active` 下沉 `1px`。
- **禁无限循环动画**（不做 shimmer / 呼吸 / 轮转）。
- `@media (prefers-reduced-motion: reduce)` 下**全部关掉**（动画与过渡）。
- 闪卡手势的 `kcIn`（换卡入场 `.kc-in`）与飞出 `.out-r/.out-l` 是**手势词汇的一部分**（§10），不属于「无限循环动画」违规；
  同样受 `prefers-reduced-motion: reduce` 约束 —— 该模式下关掉飞出/入场/旋转，只保留瞬时切换与数据提交。

## 7. 对比度

- 正文与占位文字 ≥ **4.5:1**，大字（≥24px 或 ≥18.66px bold）≥ **3:1**。
- 按钮文字必须**一行放得下**（`.btn` 默认 `nowrap`，置灰原因 `.why` 例外允许换行）。
- **白底白字、白字浅底一律禁止**。

## 8. 禁令清单（违者不得提交）

- 禁渐变**文字**（渐变**按钮底**允许，如 `.primary`）。
- 禁玻璃模糊装饰。
- 禁 `>1px` 彩色左边框（要点就是 hairline 列表，不是左边框）。
- 禁 emoji 当图标。
- 禁嵌套卡片。
- 禁横向滚动容器：`overflow-x:auto` / `overflow-x:scroll` 一律不准出现（UI-001 **浏览态** —— 列表 / 卡片列表禁横向 carousel）；
  **闪卡复习态例外**：允许并鼓励左右滑动手势切卡（见 §10），但这是**手势**，**不落 DOM `overflow-x`**，故本禁令仍然成立。
- 禁系统字体当 display 字体（display 必须走 `--disp` 栈）。
- 禁「每节都加小标签」式的标签泛滥：微标签只标**出处与状态**。
- 不引任何依赖/框架（UI-004）：纯 CSS + 原生 JS。
- 后端 API 契约不动（字段不删不改名）；确需新增展示字段时，必须同时加测试并在 commit message 说明。

## 9. 触发点 / 覆盖路径 / 违规处置

- **触发点**：任何前端改动（新页面、新组件、改样式、改文案）。
- **覆盖路径**：`backend/frontend/{index.html,css/,js/,img/}` **全部**，无旁路（含 empty / error / loading / disabled 状态）。
- **违规处置**：不合规**不得提交**；实测回归（如旧 accent 复现、出现横滑容器）**即回滚该 commit** 并回到本规格重做。
- **机械断言**：`make ui-audit`（`scripts/ui_audit.js`）—— 两档宽 × 九路由实测
  ①间隙 ②无横滑 ③accent/theme-color ④原生面；⑤ 首页**格言当天固定**（连取两次同 ID + 大标题 == API 文案）+
  **四级进度条存在**（`.progline .bar` / `.meter .bar` / `.chap .bar` / `.cm`）+ **错题本页可达且非空白** +
  **三新页（`#/plan` / `#/weak` / `#/report`）可达 + 面包屑（`首页 ›`）+ 非空白（有条目 或 空态文案）**；
  ⑥ 三新页源码口径：**空态文案在位** + 正确率**只用后端 `accuracy` 字段**（反断言 `Math.round(...correct...)` 不得出现）。
  **非零退出码 = 失败**。没有机械断言的视觉条款视为**未完成**（`CLAUDE.md §10 元规则`）。

## 10. 闪卡手势（**仅复习卡**，UI-014 · v0.5.4 修订）

闪卡是**结构**：`.kc-scene`（`perspective:1200px`）> `.kc-card`（`transform-style:preserve-3d`）> 正/反两片 `.kc-face`（`grid-area:1/1` 叠放，`backface-visibility:hidden`）。
配色一律走令牌（正面 `--card`、背面 `--green-tint`），**不得带 coral**。行为照抄 AI学习小组app 的 knowledge deck。

| 交互 | 条款 |
|---|---|
| 点击卡面 | 3D 翻转看答案 / 收起：`.kc-card.is-flipped { transform: rotateY(180deg) }`，`0.45s`，正反面 `backface-visibility:hidden` |

- **触发点**：复习卡任何手势或卡面改动。**覆盖路径**：`js/flashcard.js` + `js/review.js` + `css/app.css` 的 `.kc-*`，无旁路。

  反向断言：`tests/test_frontend.py::test_quiz_no_longer_swipes`。原因：客观题原地作答，没有「下一张卡」的方向语义，滑动会与选项滚动争手势。
- **违规处置**：方向反了、阈值漂移、丢失竖向滚动优先、reduced-motion 未关动画、卡片两侧出现真横滑容器 → **不得提交**。

### 测验结果解析卡（QUIZ-010）
- 每题恰有一个 `.opt.mine`，使用 2px 主墨色粗框表达「我的答案」，粗框本身不表达对错。
- 正确项使用草绿与文本 `✓ 正确答案`；答对时我的项同时为 `.correct`，不得出现 `.wrong` 或叉号。
- 答错时我的项为陶橙 `.wrong` 与文本 `✗ 你的答案`，正确项仍为草绿 `✓ 正确答案`。
- 解析卡不渲染底部「你的答案 / 参考答案」对照行，不使用 ✅/❌ emoji。

## 11. 覆盖率环形图 + 掌握度五星（UI-018 / MAST-008 · v0.10.0）

### 覆盖率环形图（UI-018）
- **inline SVG**，`viewBox 0 0 64 64`，圆心 `(32,32)`，半径 `26`，`stroke-width:5`；进度用 `stroke-dasharray`（`dash gap`），**底环 = `--hair`、进度环 = `--green`**（禁新颜色）。
- 环心**两行文本**（SVG `<text>`）：`覆盖率`（`--muted` 11px）+ `c%`（`--ink` 15px/800，`tabular-nums`）；`c` **只读后端** `mastery.coverage`，前端零计算。
- 无障碍：`.ring` 加 `role="img"` + `aria-label="覆盖率 c%"`；内层 SVG `aria-hidden="true"`。
- 出现处（三处，与现有块同块）：首页学科块（`.progline`）/ 学科页书行（`.row`）/ 书页（`.meter`）；`.gauges` 组整体换行到块内第二行，不引起布局跳动。

### 掌握度五星（MAST-008）
- `stars = round(m / 20, 1)`（86% → 4.3）；5 颗 **inline SVG** 星（`viewBox 0 0 120 24`，每星 `24×24`，路径统一）；
  小数部分用 **`<clipPath>` 遮罩**（前景层 `.stars-fg` 被 `<rect width = (stars/5)×120>` 裁剪）表达，不用圆点近似。
- **空星 = `--hair`**、**实星 = `--green`**；常显一行 `掌握度 86% · 4.3★`（`★` 为内联小星 `.star-ico`，**SVG 非字符/emoji**）。
- 无障碍：`.stars` 加 `role="img"` + `aria-label="掌握度 c% · s 星"`；`m` 缺失 → 显 `—`（`.stars.none`）。
- 数值只读后端 `mastery.m`，前端零计算；保留原百分比（`.num`）与进度条（`.bar`），**不做替换**。

## 12. 图书范围面板（SCOPE-001~004 · v0.10.0 / v0.11.0）

- **入口**：首页快捷入口首格「图书」，副标题 = 当前范围文案（`图书：全部` / `图书：2/N 本（书名、书名）`），**只读后端** `/api/scope.label`，前端零计算。空范围已不是合法状态，故**不再出现「未选择」**。
- **独立钻取页** `#/scope`：`crumb(首页 › 图书范围)` + `h1 图书范围` + 范围文案微标签（`--green`）；页面纵向滚、**禁横向滚动（UI-001）**、**禁弹窗/内嵌滚动列表**。
- **每行**（复用 `.row` 块）：书名（`.l > b`）+ `学科 · 已学 x / 共 y · 覆盖率 c% · 掌握度 m%|—`（`.l > span`，`--muted`）+ **勾选框 = `.tick`**（22×22，1px 边；选中 `.tick.on` = accent 绿底 + 白描对勾，**纯 CSS、非 emoji、非 `<input>`**）。
